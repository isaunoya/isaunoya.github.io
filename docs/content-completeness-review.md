# 课件内容完整性复核

本轮交付为两份专题课件和四份比赛部分题目讲评。比赛讲评仅收录作者参与命题的题目。目标是补齐从题面到可实现解法之间
缺失的证明、执行顺序和适用条件；不以增加页数或给出满分评价替代核验。

## 两份专题课件

- 根号分治补充分块摘要与莫队状态维护的区别；二次离线事件登记与答案还原；
  P4062 前缀计数变化；P5443 改边快照和回滚顺序；MONSTER 超集累加；
  CF1716E 递归状态及空区间单位元；P5021 可选题的完整解法。
- 随机化补充条件成功率、重复次数与全程误差预算、随机源假设和超时的含义；
  Quickselect 不变量与哈希初始化；CF436E 确定性分类和方案恢复；
  CF1198F 种子集合与完整 DP；P3765、P8817 的确定性替代；CF1799F 操作支配
  关系与 DP；动态可达的秩一更新、重建重试以及全程误差的并集界。
- 保留既有题目与原题链接，不用额外题量掩盖现有解说的缺口。

## 主讲与选读的安排

根号专题按序列分块、莫队与二次离线、参数与轻重分类、时间分块展开，主讲在
PDF 第 51 页结束。六组拓展列明前置知识，并提供题目入口和返回主讲的链接。
P4887 增加事件登记、前缀求值、答案还原图；P8330 增加轻源与轻目标分支的
边界变化图。原有 125 个二级主题和 40 个题面或模型首屏均保留。

随机化从 Quickselect 开始，随后用矩阵验证引入错误概率，再讲多重集指纹与
多数见证，到 PDF 第 35 页结束主讲。数据结构应用、随机顺序的方法边界和
高级构造分开选读；一般概率、随机源和适应性讨论可从正文跳转到附录。
原有 112 个二级主题、29 个题面或模型首屏均保留。

主讲的概率参数与工作量一起计算。Freivalds 用独立重复控制总误差，ABC367F
明确两组权值的独立性，P3765 的预算计入最后一次全体统计，CF1523D 的运行
时间计入重复次数。Freivalds 和多数见证新增的图示分别说明条件比特和见证区域。
页码均为阅读器的物理页码，不是课件页脚的逻辑页码。

## 核验依据

六份 PDF 均经过编译、目录与外链注释检查、越界文字检查和渲染审查。
共检查 84 个题面首屏，逐个与单独编译的题面比较，确保提示和解法尚未显示。
一页内不混入两个题；主题、正文大小、作者信息及分步展示保持统一。

小实例验证使用独立枚举或暴力答案，主要覆盖：

- 根号课件：8191 个前缀序列、11440 组局部配对、12130 个树阈值、25500 个
  翻转状态摘要、51000 个超集伤害值。
- 随机化课件：21760 个星数目标、10824 个完整划分、35460 个指定种子划分、
  500 张图的前三候选、30000 个操作顺序比较，以及选择与多数候选验证。
- 广西与四川：3279 个字符串、19447 组含重复值的 MST、1500 张分层 DP 图、
  9840 个计数字符串、510 个精确有理数策略枚举。
- 女生赛与 Online II：5913 个排列、5914 棵递增树、2550 个字符串复制计数、
  23520 个离线矩形、628 个分配实例、1092 个出售顺序实例、33861 张图、
  1441 棵 Prüfer 树和 15000 次分块操作。L 的 Trie 实现另通过 654240 次修改、
  2160000 次暴力查询比对，覆盖 48449 次重建；正式样例一致。

专题验证命令见 `lectures/README.md`，比赛验证命令见 `editorials/README.md`。
验证用于发现转移与边界错误，不替代课件中的证明。新增算法及四川 C 的数学
推导已由另一位审阅者交叉核对，最后修复了发现的缺失条件与公式绑定问题。

## 保留的条件与限制

- 哈希与抽样仍有课件中列出的错误概率；固定输入、独立采样等假设须满足。
- 动态矩阵括号摘要没有声称四个元素等于四次独立验证；给出了可用的静态精确
  替代。动态可达的重建预算适用于固定操作序列。
- CF436E、CF739E、CF1799F 的严格保守带宽均未证明满足原题时间预算。
  它们放在随机顺序的方法边界选讲中；已有完整确定性替代的题目提供相邻入口。
- 四川 C 的 300 次界包含严格有限整数验证，但不是形式化的浮点舍入证明。
- 正式题面优先于本地早期题稿，例如 Online II L 使用正式的普通区间和查询。

## 网站与维护

唯一正文源为 `lectures/*/slides.typ` 与 `editorials/*/slides.typ`。
`npm run build` 编译全部六份 PDF，再构建网站。About 仅提供直接 PDF 入口，
入口标注 `[AI rewrite]`；无独立题解 HTML 页，不在 PDF 中重复标注 AI 或修订日期。

L 的讲解进一步压缩为分块映射与复杂度、Trie 子树共享与边界拼接，以及
64 MB 限制下定期重建的摊还证明。节点表示和标记下降留在配套代码，不在
课件中逐字段讲解。单次重建是 O(N)，修改的 O(log N) 保证是均摊界。

本轮教学重排未修改既有 C++ 和算法验证脚本，未重复运行此前的穷举测试；
复核集中于内容保留、新图语义、概率代数、84 个题面首屏的像素比较和链接。
两份专题另由对方作者交叉审查，主审独立核对改动与渲染后验收。
