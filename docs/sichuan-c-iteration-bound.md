# 四川 C：同步值迭代的轮数上界

在题目范围 `N ≤ 100000` 内，下述同步 Bellman 迭代在精确算术下至多进行
300 次更新，就能使残差给出的答案区间宽度小于 `10^-8`。数值常数来自覆盖
完整有限范围的整数验证；一般规模另有纯解析的轮数上界。

## Bellman 算子与残差

记 `S_N(x)` 为不超过 N、与 x 存在整除关系的正整数集合，自身只计一次。
状态零吸收，每步先选择等待或随机动作，再减一。定义

`(T_N h)(x) = 1 + min(h(x-1), avg_{y∈S_N(x)} h(y-1))`，`h(0)=0`。

从等待策略 `h_0(x)=x` 出发，令 `h_(t+1)=T_N h_t`。该算子保序，故
`f ≤ h_(t+1) ≤ h_t`，其中 f 为最优期望。每轮必须同时重新计算两个动作。

任意策略在未来 N 步内，若全程等待必然吸收；否则第一次随机动作选到一的
概率至少为 `1/N`。因此所有策略均有有限期望吸收时间。截断最优策略，之后
改为等待，其残余代价随截断时刻趋于零，所以 `h_t → f`。有限状态与有限
动作保证可选取达到 Bellman 最小值的最优平稳策略。

对旧数组 h 完整算出 `g=T_N h`，令 `δ=max_x(h(x)-g(x))`。对任意动作，
`h(x) ≤ 1+E[h(X')]+δ`。沿最优策略累加到吸收，得到

`h(x)/(1+δ) ≤ f(x) ≤ h(x)`。

停止宽度为 `max_x h(x) δ/(1+δ)`。这个证书属于旧数组 h，不能交换数组后
再混用旧残差。残差证明了停止时的精度，还需要下面的尾界证明何时停止。

## 最优值势函数与几何尾界

沿最优平稳策略，非零状态满足 `E[f(X_(k+1)) | X_k]=f(X_k)-1`。
若 `f≤H`，令 `ρ=1-1/H`，则 `f(x)-1≤ρ f(x)`。零状态势函数为零，故

`E[f(X_k)] ≤ Hρ^k`，`Pr(τ>k) ≤ Hρ^k`。

第二式使用正状态 `f(x)≥1`。若某一轮已经有 `f≤h_t≤H`，先执行最优策略
k 步，再采用 h_t 所对应的策略，可得

`0 ≤ h_(t+k)-f ≤ H²ρ^k`。

又因为 `h-T_N h ≤ h-f`，上述残差区间宽度至多 `H³ρ^k`。

## 覆盖所有 N 的整数上界

令 `U=100000`，在统一状态域 `0..U` 上定义

`A_v(x)=max_{x≤M≤U} avg_{y∈S_M(x)} v(y-1)`，

`R(v)(x)=1+min(v(x-1),A_v(x))`。

它支配每个具体 N 的 Bellman 算子。对固定 x，约数部分固定，随 M 改变的
只有倍数列表的前缀；只需依次加入 `2x,3x,…`，即可枚举所有不同的平均值。
每轮汇总全部约数及倍数前缀的时间为 `O(U log U)`。

取尺度 `s=10^6`，初始 `u_0(x)=sx`，迭代

`u_(t+1)(x)=s+min(u_t(x-1),ceil(A_(u_t)(x)))`。

所有平均值都向上取整，算子保序；因此对全部 `x≤N≤U` 都有
`h_t^N(x)≤u_t(x)/s`。这不是只计算 N=U，也不是抽样若干 N。

可复验程序为 [`../editorials/verify-sichuan-c-bound.cpp`](../editorials/verify-sichuan-c-bound.cpp)：

```sh
c++ -O2 -std=c++20 editorials/verify-sichuan-c-bound.cpp -o /tmp/verify-sichuan-c
/tmp/verify-sichuan-c
```

输出第 40 轮 `max u_40=9788341`，从而所有允许的 N 均有 `h_40<10`。
程序只使用整数运算，并逐轮断言各分量不增。初值至多 `10^11`，累计项数
至多 `10^5`，求和至多 `10^16`，加上向上取整修正仍在有符号 64 位范围内。
另一份独立实现也得到相同的第 40 轮最大值。

取 `H=10,t=40`。第 300 次更新计算 `T_N h_299`，并检查旧数组 `h_299`；
此时 `k=259`，区间宽度至多

`1000·(9/10)^259 < 10^-8`。

最终不等式也可用大整数验证：`1000·9^259·10^8 < 10^259`，已包含于
`python3 editorials/verify-editorials.py`。因此本题范围内精确迭代次数 `K≤300`，
总时间 `O(KN log N+Q)`，空间 `O(N)`。

## 不依赖有限验证的解析上界

取 `B=ceil(sqrt(N))`。状态不超过 B 时一直等待；否则随机操作，直到进入
小状态或直接结束。若 B≥N，直接等待。对高状态 x，集合大小至多
`τ(x)+floor(N/x)-1≤2sqrt(N)+N/B`；每次随机选到一的概率至少为该上界
的倒数。因此这一策略的期望不超过 `H=4sqrt(N)+1`，最优值也不超过 H。

这里初值 h_0 仍可能大于 H。截断后等待的代价至多 N，所以应使用
`h_k-f≤NHρ^k`，残差宽度至多 `N²Hρ^k`，而不能直接套用 `H³ρ^k`。
由此得到一般规模的 `O(sqrt(N) log(N/ε))` 轮上界。

## 数值实现的范围

300 次结论是精确算术的证明。浮点实现仍采用同步数组、残差检查和精度余量。
此处没有给出针对特定浮点平台的有向舍入或区间算术证书，不能把该结论
改写为“任意平台运行 300 次必然满足浮点精度”。
